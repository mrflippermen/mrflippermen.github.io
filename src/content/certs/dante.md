## 🔒 Confidential Assessment Profile

**Target Environment**: `Hybrid Corporate Network`
**Objective**: `Full Infrastructure Compromise`

**Dante** es un laboratorio inmersivo diseñado para simular una red corporativa híbrida (Windows y Linux). Sirve como campo de entrenamiento para metodologías de intrusión que requieren versatilidad y adaptabilidad, obligando al operador a saltar entre diferentes sistemas operativos para alcanzar el objetivo final.

---

## ⚔️ Tactical Competencies

### 1. Weaponization & Exploitation
*   **Custom Exploit Dev**: Desarrollo de Stack-based Buffer Overflows.
*   **PoC Modification**: Adaptación de exploits públicos para bypassear restricciones específicas.

### 2. Deep Network Pivoting
*   **Multi-Stage Tunneling**: Encadenamiento de túneles (SSH, Chisel, Ligolo) para alcanzar segmentos profundos de la red.
*   **Traffic Encapsulation**: Evasión de segmentación de red.

### 3. Hybrid Operations (Win/Lin)
*   **Cross-Platform Attacks**: Uso de credenciales obtenidas en Linux para comprometer dominios Windows.
*   **Privilege Escalation**: Abuso de SUIDs, Capabilities y Kernel Exploits en Linux; Token Impersonation y DLL Hijacking en Windows.

## 🏆 Operational Impact

Completar Dante demuestra el perfil de un **Pentester "Todoterreno"**, capaz de navegar redes complejas y segmentadas, comprometiendo tanto servidores Linux como infraestructuras Windows Active Directory.
